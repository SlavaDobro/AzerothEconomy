# Меню сервера

Модуль `ru.terrawow.main.menu` заменил CommandPanels. Он включается флагом `modules.menus: true` в `config.yml`. Меню лежат в `plugins/TerraWoWmain/menus/*.yml`, и в одном файле может быть несколько меню. После правки выполните `/twm menu reload` или `/twm reload`.

## Команды

| Что | Команда | Кто может |
|---|---|---|
| Главное меню | `/menu`, `/wow`, `/twm menu` | все |
| Любое меню | `/twm menu <id>` | все (себе) |
| Открыть меню игроку | `twm menu <id> <ник>` | консоль или `twm.admin` |
| Список меню / перечитать | `/twm menu list`, `/twm menu reload` | `twm.admin` |

Кнопки MMOCore открывают меню из консоли: `dispatch_command{format="twm menu main <caster.name>";from_console=true;target={type=caster}}`. Кнопки «Главное меню» в окнах плагина (маунты, питомцы, раса) открывают `main` напрямую.

## Какие меню есть и кто их делает

| ID | Что | Создаёт |
|---|---|---|
| `main` | Главное меню (`/menu`) | `tools/wow_menu_panels.py` |
| `professions` | Профессии | `tools/wow_menu_panels.py` |
| `change_class` | Смена класса со сбросом | `tools/wow_menu_panels.py` |
| `custom_classes` | Особые классы | `tools/install_custom_class.py` |
| `class_<id>` | Карточка особого класса с выбором | `tools/install_custom_class.py` |

Инструменты описывают меню так же, как раньше для CommandPanels, а `tools/twm_menus.py` переводит это в формат ниже. Если файл перезаписывает инструмент, правьте данные в инструменте. Свои меню можно писать руками в отдельный файл.

## Формат

```yaml
main:                                  # ID меню
  title: '<#8A5A12>✦ <#3A2410>Главное меню <#8A5A12>✦'
  rows: 6                              # 1–6
  fill: frame                          # этот предмет — во все пустые ячейки (необязательно)
  items:
    frame: {icon: BLACK_STAINED_GLASS_PANE, name: ' '}    # пустое имя = без подсказки
    hero:
      slot: 4                          # или slots: [0, 8, '45-53']
      icon: 'head:{player}'            # MATERIAL | nexo:<id> | mmo:<TYPE>:<ID> | head:<ник>
      model-data: 2058                 # custom model data (необязательно)
      glint: true                      # блеск зачарования
      name: '<#FFD100>{player}'
      lore:
      - '<gray>Класс: <white>%mmocore_class%'
      - '&7Кошелёк: &6%twm_gold%'
      click: [close, 'delay 1', 'console mmocore:player {player}']   # ЛКМ и ПКМ
    class_choose:
      slot: 13
      show-if: '%mmocore_class_id% == HUMAN'   # в одной ячейке побеждает первый показанный
      icon: BEACON
      name: '<#1EFF00>✦ Выбрать класс'
      click: [close, 'console mmocore:class {player}']
    class_current:
      slot: 13                         # покажется, если class_choose скрыт
      icon: BEACON
      name: '<#FFD100>Ваш класс: %mmocore_class%'
      left-click: ['open change_class']
      right-click: [close]
      require: '%mmocore_level% >= 10'  # условие нажатия
      deny: ['message <#FF4040>Нужен 10 уровень']
```

**Действия** выполняются по порядку:

| Действие | Что делает |
|---|---|
| `close` | закрыть окно |
| `open <id>` | открыть другое меню |
| `delay <тики>` | подождать, 20 тиков = 1 секунда; остальное выполнится позже |
| `console <команда>` | команда от консоли (для команд, которые игроку не разрешены) |
| `player <команда>` | команда от игрока |
| `chat </команда>` | игрок «пишет» в чат, нужно для команд, которые плагины ловят из чата |
| `message <текст>` | сообщение игроку |
| `sound <звук> [громкость] [тон]` | звук, например `sound ui.button.click 1 1.2` |

**Тексты.** Работают цвета MiniMessage (`<gold>`, `<#FFD100>`, `<bold>`) и обычные `&`-коды. `{player}` заменяется на ник. Плейсхолдеры PlaceholderAPI (`%mmocore_level%`, `%twm_gold%`) работают в текстах, командах и условиях.

**Условия** (`show-if`, `require`):
- `a == b`, `a != b` — сравнение без учёта регистра;
- `>`, `>=`, `<`, `<=` — для чисел;
- `perm:узел` и `!perm:узел` — проверка права;
- `&&` (и) и `||` (или) — объединение условий.

Пустое условие всегда выполнено.

**Ошибки.** Если в файле ошибка (неизвестное действие, ячейка вне окна, `open` несуществующего меню), модуль меню не запустится, а в консоли будет файл и место ошибки. Экономика и остальные модули при этом работают.

## Единый вид всех окон

Так устроены все окна сервера: меню, окна MMOCore (книга заклинаний, таланты, персонаж, группа…) и окна плагина (экономика, маунты, питомцы, раса).

| Где | Что |
|---|---|
| Левый нижний угол | **◂ Главное меню** — всегда здесь, единственный выход в другие окна (в самом главном меню тут **✘ Закрыть**) |
| Центр нижнего ряда | **❓ Как пользоваться** — по шагам, что делать именно в этом окне |
| Рядом с ❓ | **◂ Назад: …** — только во вложенных окнах одного раздела (облики маунта → журнал, вкладка банка → банк) |
| ◂ ▸ в нижнем ряду | страницы списка |
| Справа внизу | действия этого окна: спешиться, пригласить, покинуть, сбросить ветку |
| Верх по центру | заголовок окна или выбранный элемент |

Кнопок-переходов в другие разделы внутри окон нет. Окна MMOCore приводит к этому виду `tools/wow_gui_layout.py`. Его можно запускать повторно; запускать **последним**, после `wow_forever_mmocore.py`, `wow_menu_panels.py` и `install_custom_class.py`. Новые окна плагина делайте так же.

## Нарисованный фон окна

Вместо серых ячеек сундука окно может показывать картинку. Заголовок начинается со символа шрифта `wowforever:gui`, и картинка этого символа размером с окно (176×222) закрывает весь сундук. Плагин тут ни при чём: картинка и шрифт лежат в ресурспаке Nexo.

```yaml
title: '<font:wowforever:gui><white></white></font><#FFD100>Главное меню'
```

- `` сдвигает на 8 пикселей влево, к краю окна; `` — сам фон; `` возвращает к месту заголовка.
- `<white>` обязателен, иначе игра затемнит картинку цветом заголовка.
- У такого меню не должно быть `fill` и стекла в пустых ячейках: иначе стекло закроет фон.
- Картинки и шрифт создаёт `tools/wow_gui_backgrounds.py` (там же функция `background_title`), предпросмотр с номерами ячеек — `models/gui/<имя>_preview.png`. После изменения: `/nexo reload all`.

У `main` свой фон под его раскладку. **Все остальные окна** (меню, окна плагина, MMOCore) получают фон автоматически: при открытии окна-сундука плагин (`UiBackgrounds`) меняет заголовок на «фон `panel_<ряды>` + прежний текст золотом». Если в заголовке уже есть свой фон, его не трогают. Пока фоны включены (`ui-backgrounds: true` в `config.yml`), стеклянные рамки не ставятся: в меню пропускаются предметы без имени и `fill`, в окнах MMOCore рамки `frame`/`frame-gold` удаляет `wow_gui_layout.py`.

## Иконки WoW

Кнопки показывают иконки из WoW: `icon: nexo:wf_icon_<ключ>`. Их скачивает с wowhead и превращает в предметы Nexo `tools/install_wow_icons.py` (список `ICONS`: ключ → имя иконки на wowhead). Иконка «Ваш класс» в главном меню своя у каждого класса (`show-if` по `%mmocore_class_id%`). «◂ Главное меню» во вложенных окнах — камень возвращения. Если Nexo-предмета нет, на кнопке будет барьер.

- **Окна плагина** (экономика, маунты, питомцы, раса) берут иконки через `UiIcons`: если Nexo-предмета нет, остаётся обычный предмет. Выключить: `ui-icons: false` в `config.yml`. Старая настройка `nexo-icons.<МАТЕРИАЛ>` по-прежнему главнее.
- **Окна MMOCore** получают `item-model: wowforever:icon/<ключ>`: для них `install_wow_icons.py` пишет свои модели в пак. Проставляет `tools/wow_gui_layout.py` (списки `ICON_BY_ITEM` и `ICON_BY_FILE`).

## Звуки окон

Плагин озвучивает все окна сервера: свои, меню и окна MMOCore. Звук выбирается по тому, что произошло за 2 тика:
- окно открылось из игры — `open`;
- окно закрылось в игру — `close`;
- одно окно сменилось другим (раздел, страница, «Назад») — `page`.

Звуки — из WoW (книга заклинаний), их кладёт в пак `tools/install_ui_sounds.py` (`wowforever:ui.open|close|page`). Настройки в `config.yml`:

```yaml
ui-sounds:
  enabled: true
  open: 'wowforever:ui.open'     # пустая строка — без звука
  close: 'wowforever:ui.close'
  page: 'wowforever:ui.page'
  volume: 1.0
  windows: ['ru.terrawow.', 'io.lumine.mythic.lib.gui.', 'net.Indyuce.mmocore.']   # чьи окна озвучивать
```
