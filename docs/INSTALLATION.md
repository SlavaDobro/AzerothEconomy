# Установка

1. Используйте совместимую сборку Paper 26.3 и Java 25+. Точные проверенные версии перечислены в INTEGRATIONS.md.
2. Штатно остановите сервер и сделайте полную резервную копию, включая playerdata и базы данных.
3. Скопируйте `dist/TerraWoWmain-1.1.0.jar` в `server/plugins/`. Русские конфигурации доступны в `dist/config` и создаются автоматически при первом запуске.
4. Отключите другие провайдеры основной экономики. В проверенной сборке CMI `Economy.Enabled=false`. Перенос старых денег не выполняется автоматически.
5. Меню сервера создаются инструментами (`tools/wow_menu_panels.py`, `tools/install_custom_class.py`) в `plugins/TerraWoWmain/menus/`. Отдельный плагин меню не нужен.
6. Запустите сервер, выполните `twm economy diagnose`, затем `/twm economy` в игре. Выполните проверки из README двумя тестовыми игроками.

Данные рабочей установки, резервные копии, сырые журналы и чужие плагины не опубликованы. Настройки тестового режима в распространяемой конфигурации выключены. Ограничения описаны в TESTS.md и API.md.
