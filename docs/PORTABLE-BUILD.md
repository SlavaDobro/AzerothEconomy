# Сборка на другом компьютере

Весь код AzerothEconomy находится в `src/main/java`; тесты — в `src/test/java`; русские ресурсы — в `src/main/resources`. Клонирование репозитория или Download ZIP переносит полный проект. Каталоги server, world, playerdata и тестовые БД не являются исходниками плагина и не нужны для обычной сборки.

## Требования

- JDK 25 или 26 (не только JRE), переменная JAVA_HOME или Java в PATH.
- Для Windows: PowerShell; для Linux/macOS: bash, curl и sha256sum/shasum.
- Интернет для Maven Central, PaperMC, JitPack и официального релиза PlaceholderAPI.

## Команды

Windows: `./build.ps1`. Linux/macOS: `chmod +x mvnw build.sh && ./build.sh`.

Скрипты скачивают PlaceholderAPI 2.12.3 в игнорируемую папку `.build-deps`, проверяют `deps/placeholderapi.sha256` и запускают Maven Wrapper. Paper API 26.3.build.244-stable и VaultAPI 1.7 — provided-зависимости Maven, их классы в JAR плагина не включаются. Закрытые Nexo/MMOItems API в compile classpath не нужны: интеграция использует публичные методы установленных плагинов через reflection.

После подготовки PlaceholderAPI можно запускать `mvnw clean verify` непосредственно. Выходной JAR — `target/AzerothEconomy-1.0.0.jar`. Тесты, требующие живого MariaDB, без отдельного флага пропускаются; обычные SQLite/JVM тесты выполняются.

## Первоначальная сборка сервера

`pom-server.xml` и `build-server.ps1` сохраняют исходный режим с точными установленными серверными JAR; `deps/manifest.json` фиксирует их хеши. Этот режим нужен для воспроизведения исходного бинарного артефакта из dist, а не для обычной работы с исходниками. Публичная сборка может отличаться байтами JAR из-за предоставляемых API/метаданных сборки; Java-код плагина один и тот же.

## Запуск на сервере

Для запуска нужны Paper и установленные интеграции, которые вы планируете использовать. Публикация исходников не предоставляет лицензии на сторонние платные плагины. Их отсутствие на компьютере разработчика не мешает обычной компиляции. Проверенные версии и ограничения перечислены в INTEGRATIONS.md и TESTS.md.
