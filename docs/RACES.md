# Расы Азерота

Модуль `ru.terrawow.main.race`. Он включается флагом `modules.races: true` в `config.yml`, все настройки лежат в `plugins/TerraWoWmain/races.yml`. Файл создаётся при первом запуске; после правки выполните `/race reload`.

## Как это выглядит в игре

1. При первом входе открывается окно **создания персонажа**. Пока раса не выбрана, закрыть его нельзя; у `terrawow.admin` можно.
2. Шаги: **фракция** (Альянс / Орда) → **раса** → **пол** → **подтверждение**. В карточке расы видны рост, расовые особенности, способность и доступные классы.
3. После выбора, если у игрока ещё нет класса, открывается выбор класса MMOCore (`settings.after-choice-command`).
4. `/race` — карточка вашей расы, `/racial` — расовая способность. Кнопка «Раса» есть в `/menu`.

Расу выбирают один раз. Сменить её может только администратор: при смене снимаются старые рост, пассивки и скин и ставятся новые.

## Что настраивается в races.yml

- **passives** — постоянные бонусы:
  - `stat:` — стат MythicLib/MMOCore (`MAX_HEALTH`, `MAX_MANA`, `CRITICAL_STRIKE_CHANCE`, `DODGE_RATING`, `ICE_DEFENSE_PERCENT`…). `type: relative` — проценты, `flat` — число. Ключ модификатора — `terrawow_race`.
  - `attribute:` — атрибут Minecraft (`knockback_resistance`, `oxygen_bonus`, `block_break_speed`…) с `operation`.
  - Бонус без `stat` и `attribute` только описывается.
- **racial** — способность: `cooldown` и список `actions`:
  - `cleanse`, `effect`, `area` — врагов вокруг; игроков только при `players: true` и не своей фракции;
  - `heal`, `mana`, `velocity`, `safe-fall`;
  - `stealth` — невидимость, пока стоите и не атакуете;
  - `sound`, `particle`.
- **classes** — какие классы MMOCore доступны расе (таблица как в WoW, со времён Cataclysm). Класс, которого нет ни у одной расы (например, особые классы), доступен всем. Стартовый `human` разрешён всегда. Принудительная смена `mmocore class force` ограничения не проверяет.
- **skins** — подписанные скины (`value` + `signature`). Обычно их заполняет `tools/sign_race_skins.py` в отдельный файл `race-skins.yml` рядом с `races.yml`, и он складывается с `races.yml`. При выборе расы и пола берётся случайный скин, и выбор запоминается. При сбросе расы возвращается собственный скин игрока. Модуль `skin` в CMI выключен, чтобы CMI не перебивал скин.

## Команды

| Действие | Команда | Право |
|---|---|---|
| Карточка расы / создание персонажа | `/race` | `terrawow.race` (true) |
| Расовая способность | `/racial` | `terrawow.race` |
| Поставить расу | `/race set <ник> <раса> [male\|female]` | `terrawow.admin` (op) |
| Сбросить (снова выбор) | `/race reset <ник>` | `terrawow.admin` |
| Узнать расу | `/race info [ник]` | `terrawow.admin` |
| Открыть выбор игроку | `/race open <ник>` | `terrawow.admin` |
| Перечитать races.yml | `/race reload` | `terrawow.admin` |

ID рас: `human dwarf nightelf gnome draenei worgen orc undead tauren troll bloodelf goblin`.

Данные игроков хранятся в `plugins/TerraWoWmain/races/players/<uuid>.yml`: раса, пол, номер скина и собственный скин для отката.
